# Quickstart

1. `cd backend; alembic upgrade head`, then run backend and frontend as before.
2. Quick Capture "remind me to call the bank on Friday" -> task with Friday's date appears on `/tasks` without reload.
3. "I parked on level 3" and "asdf" -> notes created with links.
4. "delete my grocery note" -> Confirm/Cancel card; nothing changes until Confirm.
